## Compiler isolation invariant

Parallel source editing is safe; parallel Cargo use of the same target across
divergent worktrees is not. Cargo dep-info contains relative paths and reused a
same-package/same-feature library from another worktree as fresh, producing a
false missing-symbol failure. The unchanged policy branch passed immediately
after clearing only `aiperf-runtime` artifacts and rebuilding it alone.

Therefore serialize Cargo invocations against
`/mnt/4tb/aiperf-streaming-target`, and run them only after the tested worktree
is rebased onto its intended base. Keep `RUSTC_WRAPPER` intact. Use:

```bash
source /home/anthony/nvidia/projects/aiperf/ajc/rust/.venv/bin/activate
export CARGO_TARGET_DIR=/mnt/4tb/aiperf-streaming-target
export TMPDIR=/mnt/4tb/aiperf-streaming-tmp
export CARGO_PROFILE_DEV_DEBUG=0
export CARGO_INCREMENTAL=0
```
