### NumPy `numpy.random`

**Asset Information:**
- **File(s)**:
  - [`rust/runtime/src/rng/compat/numpy_pcg64.rs`](rust/runtime/src/rng/compat/numpy_pcg64.rs) — Rust re-implementation of `SeedSequence` + PCG64 bit generation
  - [`rust/runtime/src/rng/compat/numpy_generator.rs`](rust/runtime/src/rng/compat/numpy_generator.rs) — Rust re-implementation of `Generator` methods (`random`, `standard_normal`, `integers`, `bytes`, `choice`)
  - [`rust/runtime/src/rng/compat/ziggurat_constants.rs`](rust/runtime/src/rng/compat/ziggurat_constants.rs) — the `ki`/`wi`/`fi` double-precision ziggurat tables, extracted verbatim
- **Source**: [numpy/numpy](https://github.com/numpy/numpy), `numpy/random/{bit_generator.pyx,_generator.pyx,src/distributions/ziggurat_constants.h}` (verified against the 1.26.4 sdist; stream-stable through 2.5.1)
- **Author**: NumPy Developers; the `numpy.random` bit generators additionally © Kevin Sheppard
- **License**: BSD-3-Clause (NumPy) / dual NCSA–BSD-3-Clause (`numpy.random`)
- **Usage**: Byte-exact algorithm ports (not literal source copies, except the ziggurat constant tables) used to reproduce `np.random.default_rng(seed)` draw sequences bit-for-bit from Rust, for parity with AIPerf's Python dataset/sampling code paths.

### CPython `random` module

**Asset Information:**
- **File(s)**:
  - [`rust/runtime/src/rng/compat/python_mt.rs`](rust/runtime/src/rng/compat/python_mt.rs) — Rust re-implementation of the MT19937 core (`Modules/_randommodule.c`) and `gauss`/`expovariate`/`gammavariate` (`Lib/random.py`)
  - [`rust/runtime/src/rng/compat/python_random.rs`](rust/runtime/src/rng/compat/python_random.rs) — Rust re-implementation of `random.Random`'s scalar draw methods (`choice`, `sample`, `randrange`, `randint`, `uniform`, `choices`)
- **Source**: [python/cpython](https://github.com/python/cpython), `Lib/random.py` and `Modules/_randommodule.c` (verified against CPython 3.12.10; MT19937 stream-stable across the 3.x series)

- **License**: PSF License Version 2
- **Usage**: Byte-exact algorithm ports used to reproduce `random.Random(seed)` draw sequences bit-for-bit from Rust, for parity with AIPerf's Python dataset/sampling code paths.
