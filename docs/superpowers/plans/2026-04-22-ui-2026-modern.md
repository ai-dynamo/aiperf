# Operator UI: push to 2026-modern aesthetic

**Goal:** Take the operator web UI from "solid internal devtool" to "polished product UI" without changing information architecture.

**Branch:** `ajc/k8s`. `git commit --no-verify -s`. No `git stash`.

**Scope:** three tasks, sequential then parallel.

---

## Task G1 — Design-system foundation (BLOCKING)

Sets the typography and surface tokens the other tasks build on.

**Files:**
- `src/aiperf/operator/ui/style.css` — major refactor (structured into clear layers: reset → tokens → typography → surfaces → components). Keep existing class selectors — don't rename anything.
- `src/aiperf/operator/ui/index.html` — swap the `fonts.googleapis.com` import: keep mono (JetBrains Mono), add **Geist** (`https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600&display=swap`). Drop IBM Plex Mono.

**Typography rules:**
- `body { font-family: var(--font-sans); font-size: var(--fs-md); color: var(--text-primary); }` — sans body
- `.mono, code, pre, kbd, .kpi-val, .kpi-unit, .metric-val, td.number, .hero-clock-val` → `font-family: var(--font-mono)`. Numbers, IDs, test-ids, paths, code STAY mono.
- `.card-title, .section-title, h1, h2, h3` → sans, `font-weight: 600`, `letter-spacing: -0.01em`.
- Reduce all `text-transform: uppercase` to tracking-wide labels only (KPI label, card-title eyebrow) — body text stops being uppercase.

**Surface hierarchy:**
- `body { background: var(--surface-0); }`
- `.card { background: var(--surface-1); border: 1px solid var(--border-subtle); box-shadow: var(--shadow-inner-glow); border-radius: var(--radius-md); }`
- `.card:hover { background: var(--surface-2); }` — only for interactive cards; add to `.kpi-tile`, `.job-row`, `.hero` (when clickable).
- Nav pill `.tab.active { background: var(--surface-2); box-shadow: var(--shadow-xs); }`

**Global polish:**
- `* { box-sizing: border-box; }` already there or add.
- `body { font-feature-settings: 'ss01', 'cv11', 'tnum' 1; }` — tabular numerals so KPIs don't jump width when values change.
- Selection color: `::selection { background: var(--accent-green-dim); color: var(--accent-green); }`

**Verify:** run e2e after G1 (`uv run pytest tests/e2e/operator_ui/ -m e2e -n auto`). Expect same pass count (44/1). Rendering will look different but class selectors unchanged → tests unaffected.

**Commit:** `feat(operator-ui): design-system foundation — Geist sans body, layered surfaces, token scale`
