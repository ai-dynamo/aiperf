# Origin #49 finding: verbatim system prompts

Upstream commit `88242293b552db96b90b2e3999bbfa93488c994f` adds a
dataset-wide verbatim system prompt selected from inline text or one UTF-8
file. The feature is not merely a pair of flags: the resolved text participates
in dataset composition and cache identity, composes with authored system
messages, and must reach both OpenAI-shaped and Anthropic-shaped production
requests without mutating shared conversation state.

## Applicable upstream test mapping

The Rust port must rewrite the applicable assertions rather than invoking the
Python tests:

- Resolution: inline, file, unset, exact text, read-once ownership, and all
  three Dataset variants.
- Rejection: both sources, blank inline/file, missing, directory, invalid
  UTF-8, and a symlink in either the leaf or a parent component.
- Precedence: YAML inline/file, CLI inline/file, both CLI-over-YAML directions,
  and same-layer conflict errors.
- Compatibility: shared-system/prefix-pool conflicts, user-context allowance,
  supported and unsupported endpoint capabilities, and
  `warmup_isolation_system` with/without a static system source.
- Composition: synthetic assignment, file/public assignment, exact two-newline
  prepend, absent-feature neutrality, fixed-format/unhoisted system behavior,
  source-equivalent and source-distinct segment identities, and descendant
  rebasing.
- Production request construction: OpenAI string and content-parts leading
  system messages, repeated formatting with no restacking, Chat Embeddings,
  Responses `instructions`, Anthropic raw-block prepend/preservation, and
  raw-only/prompt-only fallbacks.
- Product integration: launch the real native binary against the in-repo mock
  server and inspect recorded OpenAI and Anthropic requests for inline/file
  projection, exact whitespace, one system message, and no duplicate prefix.

Upstream's `injected_without_a_tokenizer` assertion is not directly applicable:
native text dataset composition requires a `TextTokenizer` to construct the
token-bearing segment store. The native test instead proves the verbatim text
is stored unchanged while tokenization is performed once at composition.
Python mmap lock tests are unrelated; native has no mmap dataset cache or lock.
