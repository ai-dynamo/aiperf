# Origin #49 finding: verbatim system prompts

Upstream commit `88242293b552db96b90b2e3999bbfa93488c994f` adds a
dataset-wide verbatim system prompt selected from inline text or one UTF-8
file. The feature is not merely a pair of flags: the resolved text participates
in dataset composition and cache identity, composes with authored system
messages, and must reach both OpenAI-shaped and Anthropic-shaped production
requests without mutating shared conversation state.
