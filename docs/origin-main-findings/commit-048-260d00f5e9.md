# Origin commit 260d00f5e9: adaptive error-rate units

## Upstream intent

Upstream makes adaptive-scale `error_rate` and `request_error_rate` match the
exported `request_error_rate` metric: percentage points, with errors divided by
successful requests plus errors. Cancellations are deliberately excluded. It
also rejects thresholds outside `[0, 100]`, warns for accepted legacy-looking
values strictly between zero and one, and documents the distinct units of the
three rate metric families.

## Source and native comparison

`260d00f5e9` is already ancestral to the current shared base through the
existing origin/main ancestry, so no duplicate upstream merge is necessary.
The source changes `adaptive_scale_sla.py` and its Python unit tests; it has no
Python integration or E2E test.

Native `MetricTag::RequestErrorRate` is already exported as `100 * errors /
(successes + errors)` in `rust/runtime/src/metrics_core/accumulator.rs`. In
contrast, `DefaultSlaEvaluator` in `rust/runtime/src/adaptive_core/sla.rs`
currently returns `errors / (successes + errors + cancellations)`. Native
adaptive error-rate SLAs therefore disagree in both unit and denominator. The
same native evaluator owns direct CLI, YAML, and protocol-v2 adaptive filters,
so validation belongs there rather than in one authoring front end.

## Applicable test mapping

The upstream value/denominator regression maps to a native evaluator unit test
using two successful samples, one error, and one cancellation. Native coverage
is strengthened with alias equivalence, all-error window behavior, bounds,
legacy-threshold warning, and a real CLI-to-mock adaptive E2E that asserts the
artifact's percentage-point value. The existing cancellation and success rate
tests prove that their fractional all-terminal contracts remain unchanged.

## Native implementation and verification

`100 * errors / (successful + errors)`, reject thresholds outside `[0, 100]`,
and emit a structured `tracing::warn!` for accepted thresholds strictly between
zero and one. It leaves success and cancellation fractions unchanged.
`34d667ffb7` adds a real release-binary E2E against the Rust mock at 100% error
injection; it proves the emitted JSONL value is `100.0`, the `le: 1` SLA fails,
and the product retains its expected all-failed exit code.

`/mnt/4tb/aiperf-target-port048`: `cargo fmt --check`; 51
