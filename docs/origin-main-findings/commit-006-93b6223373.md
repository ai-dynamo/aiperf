# Commit 006 — `93b6223373`

Upstream subject: `refactor(telemetry): rename TelemetryRecord.dcgm_url → telemetry_source_url (#1200)`.

## Scope decision

**Applicable native artifact-contract migration.** Upstream makes the source
identity field vendor-neutral across records, messages, hierarchy storage,
accumulation, JSONL artifacts, dashboards, fixtures, and tests. The change is
not only an internal rename: `gpu_telemetry_export.jsonl` now serializes
`telemetry_source_url` instead of `dcgm_url`.

Native Rust already uses the neutral internal name
`GpuTelemetryRecord.endpoint_url`, and its NVML and AMD SMI origin/main fixtures
already decode `telemetry_source_url`. The public native serializer still
publishes `dcgm_url`, so the native artifact contract is missing the change.

## Code evidence

- Upstream commit `93b6223373` renames `TelemetryRecord.dcgm_url` to
  `TelemetryRecord.telemetry_source_url` and changes all JSONL fixtures and
  assertions without a compatibility alias.
- `rust/runtime/src/engine/gpu_telemetry.rs` declares `TelemetryRow.dcgm_url`,
  maps it from `record.endpoint_url`, and serializes `TelemetryRow` directly to
  the public GPU telemetry JSONL artifact.
- Runtime tests in that file and product tests in
  `rust/e2e-tests/tests/test_gpu_telemetry.rs` explicitly assert the obsolete
  key.
- `docs/specs/native-gpu-telemetry.md` still promises the historical
  `dcgm_url` spelling, contradicting the new upstream contract.

## Port decision

Replace the public JSONL key with `telemetry_source_url` and do not dual-write
`dcgm_url`. Preserve the existing value, field ordering, optional-field
omission, normalized metric map, internal `endpoint_url`, `GpuSeriesKey`, DCGM
collector types, DCGM configuration names, and test-harness `dcgm_urls()`
helpers. Those remaining DCGM names describe the collector, not the
vendor-neutral artifact field.

## Verification requirements

- A runtime serialization test must prove the exact source identity is written
  under `telemetry_source_url` and that `dcgm_url` is absent.
- The fixture-sidecar JSONL test must prove the AMD source uses the new key
  while retaining normalized metrics.
- Both product artifact assertions must use the new key and reject dual-write.
- Focused runtime and product telemetry tests must run with `sccache` and a
  `CARGO_TARGET_DIR` under `/mnt/4tb`.
